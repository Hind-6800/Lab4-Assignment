Lab 4 - Task 1

?- house = house.
true.
Reason: Same atom, they unify.

?- house = abc.
false.
Reason: Different atoms, no variable to fill, cannot unify.

?- edge(a,b) = edge(C,b).
C = a.
Reason: Same name, same arity. C unifies with a.

?- edge(a,d) = edge(C,B).
C = a,
B = d.
Reason: Same name, same arity. C = a and B = d.

?- edge(C,B) = edge(a,d).
C = a,
B = d.
Reason: Same result, order does not matter.

?- edge(A,f(g,h)) = edge(a,B).
A = a,
B = f(g, h).
Reason: Same name, same arity. A = a, B = f(g,h).

?- edge(A,A) = edge(b,c).
false.
Reason: A cannot be both b and c at the same time.

?- edge(A,A) = edge(b,b).
A = b.
Reason: A = b works for both positions.

?- A = B, B = f.
A = B, B = f.
Reason: A and B are linked, then B = f makes both f.

?- A = B, B = f, A = e.
false.
Reason: A would need to be both f and e, impossible.
